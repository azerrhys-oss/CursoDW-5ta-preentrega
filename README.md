# CURSO DE DESARROLLO WEB

Mi primer proyecto: Una página laboral de higiene y seguridad.

Ver el sitio:
https://azerrhys-oss.github.io/CursoDW-5ta-preentrega/

Ruta del codigo:
https://github.com/azerrhys-oss/CursoDW-5ta-preentrega

## Herramientas
- HTML5: estructura de las 5 páginas.
- CSS: Flexbox, Grid y media queries (768px y 1024px).
- SCSS (Sass): variables, mixins, @extend y partials. Se compila a css/style.css.
- Bootstrap 5: navbar con menú hamburguesa, carrusel y modal.
- Animate.css: animación de las imágenes.
- Google Fonts: Montserrat y Roboto.
- Git y GitHub: control de versiones con ramas.
- GitHub Pages: publicación del sitio.
- Visual Studio Code y Node.js (para compilar Sass).

## Como compilar los estilos
sass scss/main.scss css/style.css --no-source-map
